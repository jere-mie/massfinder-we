# Bulletin URL inventory and week checks, 2025–2026

> See also [filename patterns and fallbacks](bulletin-name-patterns.md), the [2026 week-by-week verification](bulletin-2026-url-verification.md), and the [2024-and-earlier archive URL inventory](bulletin-url-inventory-2024-and-earlier.md).

## Scope and results

The ten bulletin sources configured in `public/churches.json` were checked against their live archive pages. Each published direct PDF URL below was requested directly and counted valid only when the response body began with `%PDF-` (HTTP 200 or 206). The inventory contains **487 source/year URL entries for 2025** and **361 for 2026**; every listed link returned a PDF signature. One additional direct retry URL is documented below.

For 2025, each Sunday from January 5 through December 28 was compared with archive titles and combined-date cover text where confirmed. The matrix links to an issue for **516 of 520 source/week pairs**. One blank is an explicit no-bulletin week; three remain unresolved because no matching direct PDF was found in the current archive. If a date was absent from the page title, the source’s documented primary filename guess was tested. Some archives publish two or three Sundays in one file; a failed standalone guess is not counted as a failure when the linked combined PDF cover includes that date. The yearly archive for St Joseph, Sacred Heart, and St Paul is a separate page: [2025 Bulletins](https://4e1jla.sites.ecatholic.com/2025-bulletins). Their [2026 Bulletins](https://4e1jla.sites.ecatholic.com/2026-bulletins) page was also checked.

For the 2026 date-by-date result, including the two unresolved South Windsor weeks, see [the existing full verification report](bulletin-2026-url-verification.md). This inventory records the actual URLs linked by the live archive pages, including multiple published revisions when those pages expose them.
